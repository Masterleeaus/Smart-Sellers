# Titan Nova

Titan Nova is an autonomous agent-driven task creation, scheduling, channel execution and analytics extension for launching and operating new business verticals.

## Core mapping

- Agent = agent
- Task = task
- Planning horizon = task duration and future schedule coverage
- Task creation = task creation
- Scheduled execution = scheduled tasks
- Task type = task type
- Calendar = schedule
- Analytics = analytics
- Creation wizard = task engine
- Channel = generic delivery or execution destination

## Technical identity

- Folder: `TitanNova`
- Namespace: `App\Extensions\TitanNova`
- Provider: `TitanNovaServiceProvider`
- Tables: `ext_titan_nova_agents`, `ext_titan_nova_tasks`
